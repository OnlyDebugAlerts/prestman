# Prestman logo

Generated with the built-in `image_gen` tool. The original transparent PNG is
`prestman-logo.png`; `prestman-tray.png` is a 64 × 64 PNG resized with macOS `sips`.
The logo is embedded in the executable, so runtime asset paths are not required.

## Generation prompt

```text
Use case: logo-brand
Asset type: application logo and desktop tray icon for Prestman, a native HTTP API client.
Primary request: Create one polished, original compact emblem: a bold geometric letter P whose counter is a right-pointing request/send arrow, subtly evoking network request flow.
Style/medium: crisp vector-like flat graphic, simple connected silhouette, professional developer tool identity.
Composition/framing: one centered symbol, square canvas, symbol occupying about 75% of width, generous clean transparent margin; legible when reduced to 18 pixels.
Color palette: lavender and violet inspired by the application's existing purple accent (#b4a0ff and #704ad6); minimal color count, strong silhouette.
Constraints: genuinely transparent background, no enclosing square tile, no words or typography beyond the emblem, no thin detail, no mockup, no shadow, no watermark. One final logo only.
```
