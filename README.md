# Prestman

Нативный настольный клиент для HTTP и HTTPS на Rust 1.100.0 и GPUI Kit 0.10.0.

Выберите метод и укажите URL. Тело запроса вводится в первой вкладке **Body**. Вкладка **Query** показывает параметры URL отдельными парами **Name** и **Value**. При вставке URL параметры заполняются автоматически, а правки в таблице обновляют URL. Во вкладке **Headers** каждый заголовок тоже имеет отдельные поля имени и значения. Вкладка **Authorization** поддерживает Bearer Token и Basic Auth. Выбранный способ формирует заголовок `Authorization` при отправке. Справа отображаются статус, время, размер, заголовки и полное тело ответа. JSON форматируется и отображается с подсветкой синтаксиса.

Кнопка **Save** сохраняет выбранный запрос в локальный `requests.json` в каталоге данных приложения. Сохранённые запросы появляются в списке слева после перезапуска. Черновики и правки до нажатия **Save** хранятся до закрытия приложения.

Чтобы создать коллекцию, нажмите значок папки с плюсом в панели **Collections** и введите название. Перетащите запрос на коллекцию или выберите её через **Move to** в контекстном меню запроса. Для перемещения обратно выберите **Ungrouped**. Клик по названию коллекции сворачивает и раскрывает её. В контекстном меню коллекции можно создать запрос, переименовать коллекцию или удалить её, если она пуста. Коллекции и принадлежность сохранённых запросов сохраняются сразу.

В контекстном меню запроса **Copy link** копирует URL, **Copy** копирует запрос как JSON, а **Duplicate** создаёт черновик в той же коллекции.

## Клавиши

| Действие | macOS | Windows и Linux |
| --- | --- | --- |
| Создать запрос | `⌘N` | `Ctrl+N` |
| Сохранить запрос | `⌘S` | `Ctrl+S` |
| Отправить запрос | `⌘Enter` | `Ctrl+Enter` |
| Перейти к URL | `⌘L` | `Ctrl+L` |
| Перейти к списку | `⌘1` | `Ctrl+1` |
| Выбрать соседний запрос в списке | `↑` / `↓` | `↑` / `↓` |

## Сборка и запуск

Установите [rustup](https://rust-lang.org/tools/install/). `rust-toolchain.toml` задаёт нужную версию Rust. Для нативной сборки нужны системные инструменты. [Документация GPUI Kit](https://gpui-kit.com/docs/installation/)

- **macOS 15 и новее** — `xcode-select --install`.
- **Windows 10 и новее** — Rust для MSVC, Visual Studio Build Tools с профилем **Desktop development with C++**, Windows SDK с `fxc.exe` для релизной сборки и CMake в `PATH`.
- **Linux (Ubuntu)** — команды ниже. Для запуска нужен графический сеанс Wayland или X11 и рабочий драйвер Vulkan.

```bash
sudo apt update
sudo apt install build-essential clang pkg-config libfontconfig-dev libwayland-dev \
  libxkbcommon-x11-dev libx11-xcb-dev libssl-dev libzstd-dev libvulkan1
```

Запустите приложение из папки проекта.

```bash
cargo run --locked --release
```

Тесты выполняются командой `cargo test --locked`. Проверка сборки и тестов для трёх ОС описана в GitHub Actions.
